## Tips for Nano Banana / AI image tools

- If the tool has a **style** option, try “professional,” “minimal,” or “marketing.”
- Add **“no text”** or **“text-free”** if you want to add your own copy in Canva/Figma.
- For **square (1:1)** add: “square format, 1:1 aspect ratio, for Instagram.”
- If images look too “medical” or sensitive, add: “abstract, no patient data, illustration style.”
- Keep the **disclaimer** in captions: “For educational/research use only. Not for clinical diagnosis.”

Use one prompt per post and match it with the same number’s description (Post 1 image + Post 1 description, etc.) for a consistent campaign.
